# Barbershop App - Flutter Frontend


A Flutter-based frontend application for a barbershop, featuring multiple screens with responsive design, navigation, and form validation.

## Features

- **User Authentication**
  - Login screen with email/password validation
  - Signup screen with form validation
  - Forgot password functionality

- **Main Screens**
  - Home screen with featured blog posts
  - Services listing with pricing
  - Gallery showcasing barber work
  - User profile section

- **UI Components**
  - Custom app bar with back navigation
  - Responsive image cards
  - Bottom navigation bar
  - Form validation with error messages

## Screens

1. **Login Screen**  
   - Email and password fields with validation
   - Signup and forgot password options

2. **Signup Screen**  
   - Complete registration form
   - Profile picture placeholder
   - Form validation

3. **Main Screen**  
   - Featured blog post with image
   - Service highlights
   - Vertical service cards

4. **Services Screen**  
   - Featured service with image
   - Complete service list with pricing
   - Icons for each service type

5. **Gallery Screen**  
   - Showcase of barber work
   - Image cards with descriptions
   - Responsive layout

6. **Profile Screen**  
   - User profile picture
   - Account information
   - Logout functionality
